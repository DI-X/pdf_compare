Drop a PDF onto either upload panel to load it. Annotations are added independently to each side. Saved comments, highlights, and underlines use standard PDF annotation objects; text is saved as a FreeText annotation and signature images are embedded into the page. An image signature is a visual signature, not a cryptographic digital signature. Text comparison works best with digitally generated PDFs that contain selectable text. Scanned/image-only PDFs require OCR and are not text-compared by this version. Page matching uses text similarity to align inserted or removed pages; highlights are approximate word-level overlays based on PDF text positions. For privacy, files are processed locally using PDF.js from a CDN; no PDF contents are sent to a server. Internet access is required to load PDF.js and the PDF export library from their CDNs.
